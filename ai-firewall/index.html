AI Firewall

Keep sensitive data and AI actions under control.

PrismScale helps your Java applications protect sensitive information before it reaches an AI model. When the model proposes an action, your application still decides who can do what.

Reduce data exposure

A routine conversation can contain customer details or secrets. Apply local policies before sending data to your model provider.

Prevent unauthorized actions

An assistant may propose sharing a document or changing a record. Your application checks access and requires approval where needed.

Keep control inside your application

The SDK runs in your Java service. Your teams can manage policies and governance separately from the conversation.

How it fits into your application

The PrismScale SDK runs inside the Java service. It inspects supported model and tool flows locally. The configured model provider receives policy-allowed content. The Control Plane receives permitted metadata without receiving the conversation.

Integrate with your Java service

  1. Wire the supported provider

    Select the provider profile and keep its configuration fixed for the protected client. Follow the documented SDK and framework compatibility.

  2. Bind host identity and tools

    Build HostContext from authenticated application state. Register bounded tool calls and use ToolAuthorizer to enforce resource ownership and permissions.

  3. Handle approvals and uncertain outcomes

    Handle TurnResult explicitly. Use the host’s confirmation UI, stable business idempotency and reconciliation for actions with side effects.

  4. Deliver protected output

    Use OutputGuard for the authenticated recipient and destination. Keep raw replies, history and pending operation data out of application logs.
