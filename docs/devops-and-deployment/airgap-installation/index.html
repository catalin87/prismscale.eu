Air-Gapped Network Installation

Many tier-1 financial institutions, defense organizations, and intelligence agencies operate in completely disconnected (air-gapped) networks with zero outbound internet access.

PrismScale is natively designed for air-gapped operation. It requires no licensing callbacks, no cloud proxy routing, and no external package downloads.

Step 1: Exporting Container Images (Connected Host)​

On a machine with internet access, run the bundle export script (deploy/airgap/export-airgap-bundle.sh):

# Pull and save all necessary container images to a tar.gz archive
docker pull prismscale/backend:1.0.0
docker pull prismscale/frontend:1.0.0
docker pull postgres:16-alpine

docker save prismscale/backend:1.0.0 prismscale/frontend:1.0.0 postgres:16-alpine   | gzip > prismscale-airgap-bundle-v1.0.0.tar.gz

Step 2: Transfer and Import into Air-Gapped Registry​

  1. Transfer prismscale-airgap-bundle-v1.0.0.tar.gz across the secure data diode or optical media transfer station according to your internal security protocols.
  2. Load images into your internal enterprise container registry (e.g., Harbor, Artifactory, Nexus):
docker load < prismscale-airgap-bundle-v1.0.0.tar.gz

docker tag prismscale/backend:1.0.0 registry.internal.bank.com/prismscale/backend:1.0.0
docker tag prismscale/frontend:1.0.0 registry.internal.bank.com/prismscale/frontend:1.0.0

docker push registry.internal.bank.com/prismscale/backend:1.0.0
docker push registry.internal.bank.com/prismscale/frontend:1.0.0

Step 3: Install Helm Chart from Local Bundle​

In the air-gapped cluster, point your values-onprem.yaml to the internal registry:

backend:
  image:
    repository: "registry.internal.bank.com/prismscale/backend"
    tag: "1.0.0"

frontend:
  image:
    repository: "registry.internal.bank.com/prismscale/frontend"
    tag: "1.0.0"

Deploy using Helm:

helm upgrade --install prismscale ./prismscale-helm-chart.tgz   -n prismscale   -f values-onprem.yaml
