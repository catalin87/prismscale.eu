Agent Setup & Integration

The spring-prism-pro agent is designed for frictionless adoption across enterprise Spring Boot microservices. This guide covers build configurations, dependency scopes, and application properties.

Build Configuration​

Maven Setup​

Ensure your corporate repository or local Maven cache has access to the spring-prism-pro artifact:

<dependency>
    <groupId>com.prismscale</groupId>
    <artifactId>spring-prism-pro</artifactId>
    <version>1.0.0</version>
</dependency>

Gradle Setup​

implementation 'com.prismscale:spring-prism-pro:1.0.0'

Comprehensive application.yml Reference​

Below is a fully documented configuration template for your microservice:

prism:
  agent:
    # Master switch to enable or disable the runtime agent
    enabled: true

    # Control Plane connection details
    server-url: "http://prismscale-control-plane.internal.bank.com:8080"
    api-token: "${PRISM_API_TOKEN:sk-live-service-token}"

    # Unique identifier of this service registered in Control Plane inventory
    service-id: "retail-banking-advisor"
    environment: "production" # production, staging, dev

    # Dynamic rule sync configuration
    poll-interval-seconds: 300
    connect-timeout-ms: 2000
    read-timeout-ms: 3000

    # AI Firewall settings
    firewall:
      enabled: true
      mode: "ENFORCE" # ENFORCE (blocks attacks) or AUDIT_ONLY (logs without blocking)
      block-prompt-injection: true
      block-dan-jailbreak: true
      block-canary-leak: true
      block-system-prompt-override: true
      strip-zero-width-spaces: true
      normalize-leetspeak: true

    # PII tokenization settings
    masking:
      enabled: true
      mask-cnp: true       # Romanian CNP / National IDs
      mask-iban: true      # International Bank Account Numbers
      mask-emails: true    # Email addresses
      mask-credit-cards: true # PCI-DSS 16-digit card numbers
      mask-phone-numbers: true
      custom-patterns:
        - name: "INTERNAL_EMPLOYEE_ID"
          regex: "EMP-[0-9]{6}"
          replacement: "<PRISM_PII_EMPID>"

    # In-memory ephemeral token vault
    vault:
      ttl-minutes: 30
      max-entries: 100000
      deterministic-tokens: false # Set true for consistent token IDs within a session

Framework Integration​

Spring AI Integration​

spring-prism-pro includes an auto-configuration class (PrismSpringAiAutoConfiguration) that detects Spring AI on the classpath. It automatically injects a ChatClientCustomizer that attaches the PrismModelInterceptor:

@Configuration
public class MyAiConfig {
    @Bean
    public ChatClient chatClient(ChatClient.Builder builder) {
        // The builder is already pre-configured with PrismModelInterceptor
        return builder
                .defaultSystem("You are a helpful banking assistant.")
                .build();
    }
}

LangChain4j Integration​

To protect LangChain4j ChatLanguageModel instances, wrap your model with PrismLangChain4jModel:

@Bean
public ChatLanguageModel chatLanguageModel() {
    OpenAiChatModel rawModel = OpenAiChatModel.builder()
            .apiKey(System.getenv("OPENAI_API_KEY"))
            .modelName("gpt-4o")
            .build();

    // Wrap with in-process Prism protection
    return new PrismLangChain4jModel(rawModel, prismFilter);
}
